===== HEADER_02.H =====

Header file keeps things that several .c files can use:
- structures
- function prototypes
- constants

We connect it with:

#include "header_02.h"


===== HEADER GUARD =====

#ifndef HEADER_02_H
# define HEADER_02_H

// content

#endif

It protects the header from being included more than once.


===== STRUCT + TYPEDEF =====

typedef struct s_dict
{
	char	*key;
	char	*value;
}	t_dict;

struct = groups related variables together.

One t_dict contains:

key   -> "20"
value -> "twenty"

typedef gives our structure a shorter type name:

struct s_dict -> t_dict


===== USING IT =====

t_dict	entry;

entry.key
entry.value


===== WHY char * ? =====

key and value are strings.

We keep key as a string because numbers can be
bigger than unsigned int.
