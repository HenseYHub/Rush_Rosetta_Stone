===== PARSER_DICT.C =====

GOAL:

"100 : hundred"

key   -> "100"
value -> "hundred"


===== ft_separator() =====

Finds ':' in the line.

"100 : hundred"
    ^
    index 4

Returns:
index -> ':' found
-1    -> ':' not found


===== ft_get_key() =====

Gets the key from the line:

"100   : hundred"
   ↓
"100"

Flow:

find ':'
  ↓
remove spaces before ':'
  ↓
calculate key_len
  ↓
malloc(key_len + 1)
  ↓
copy key
  ↓
add '\0'
  ↓
return key


===== MALLOC / FREE =====

malloc -> give me memory
free   -> I don't need this memory anymore

Example:

"100"

[1][0][0][\0]

3 chars + '\0'
= malloc(4)

We free key AFTER we finish using it:

malloc
  ↓
create key
  ↓
return key
  ↓
use key
  ↓
free(key)


===== REMEMBER =====

'\0' -> end of string
'\n' -> new line
NULL -> no valid address / error
